# Publication PDFs

- [Technical white paper](APS-DDA-Technical-White-Paper.pdf): source-owned data, analytical decisions, exact authority and verified source actions. Includes a fictional insurance analytical example, two explanatory diagrams and visible references.
- [APS-DDA v0.1 proposed standard](APS-DDA-v0.1-Proposed-Standard.pdf): publication rendering of the preserved normative working draft, with a cover and visible bibliography. It is not a normative amendment or a ratified standard.

The authoritative editable documents are [the public white paper](../whitepaper.md) and [the normative Markdown specification](../../spec/APS-DDA-v0.1.md). Historical technical content is retained separately; preparation headers are generalised for this distribution. Historical status statements describe the October draft, not the later reference implementation.

PDFs were compiled with Typst 0.15.1 using cmarker 0.1.10 and mitex 0.2.7. Compilation passed without warnings. PDF metadata, page sizes, font/text presence and visible-reference output were checked; representative pages and figures/tables were visually reviewed. These are document-production checks, not independent technical peer review or certification.
