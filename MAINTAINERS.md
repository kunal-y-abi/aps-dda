# Maintainer

**Author:** Kunal Yadav. **Initial maintainer and repository owner:** [@kunal-y-abi](https://github.com/kunal-y-abi), using the verified account that owns [kunal-y-abi/aps-dda](https://github.com/kunal-y-abi/aps-dda).

Use [repository issues](https://github.com/kunal-y-abi/aps-dda/issues) for non-sensitive bugs, questions and proposals. Suspected vulnerabilities belong in [private vulnerability reporting](https://github.com/kunal-y-abi/aps-dda/security/advisories/new), following [SECURITY.md](SECURITY.md). For ordinary conduct concerns, request a verified private contact from the maintainer with a non-sensitive issue; do not post personal allegations or use security advisories for conduct reports. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Maintainer acceptance and release decisions concern this experimental project, not standards-body approval, independent expert review or certification. No staffed team, response deadline or independent appeals panel is claimed.
