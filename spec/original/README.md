# Original working-draft materials

The technical content of the standard, schema and 15 JSON fixtures comes from the 16 October 2026 draft. This distribution generalises the specification's preparation header; its normative requirements, schema and fixtures are unchanged. Historical status statements describe that draft, not the later reference implementation. Licensing is supplied by the repository's scope notice.

**Fixtures contain placeholder content/plan/query/decision/invocation digests.** They are historical fictional procurement structural examples, not cryptographically verified evidence or runtime inputs. The C# tests validate their original schema shape separately and reject placeholder integrity where appropriate. Runtime examples must issue newly computed artifacts and consistent references rather than relabel these as genuine signed data.

The original spec's `.example.invalid` schema identifiers are stable identifiers, not discovery or network endpoints. The SDK loads the bundle offline as an assembly resource.
